Página Nº3: La realización del juego didáctico

En esta sección se explica cómo se desarrolló el juego didáctico "Cuestionario Lunar", cuáles son las herramientas utilizadas para programarlo y cómo funciona desde que se abre hasta que termina una partida.

1. ¿En qué consiste el juego?

El Cuestionario Lunar es un juego de preguntas y respuestas sobre la Luna. El jugador debe leer cada pregunta y elegir una respuesta entre varias opciones disponibles en la pantalla.

Después de seleccionar una opción, el programa comprueba si la respuesta es correcta. Si el jugador acierta, aparece el mensaje "CORRECTO" y suma un punto a su puntuación. Si se equivoca, aparece el mensaje "INCORRECTO".

La partida continúa hasta completar las diez preguntas. Al finalizar, se muestra el puntaje obtenido y se ofrece la posibilidad de volver a jugar desde el principio.

2. Herramientas utilizadas

Para desarrollar el juego se utilizó Python junto con algunas de sus herramientas y bibliotecas. Cada una cumple una función específica dentro del programa.

Python

Python es el lenguaje de programación utilizado para escribir las instrucciones del juego. Permite establecer qué ocurre cuando el jugador comienza una partida, selecciona una respuesta o decide volver a jugar.

Tkinter

Tkinter es la biblioteca utilizada para crear la interfaz gráfica, es decir, la parte visual con la que interactúa el jugador. Permite construir la ventana, organizar las diferentes zonas de la pantalla y mostrar textos, preguntas y botones.

Random

Random es una herramienta de Python que permite realizar selecciones aleatorias. En este proyecto se utiliza para elegir las preguntas de manera que no aparezcan siempre en el mismo orden.

Lista de preguntas disponibles

La lista llamada preguntas_disponibles guarda los números de las preguntas que todavía pueden aparecer durante la partida. Cuando se elige una pregunta, su número se elimina de esta lista para evitar que vuelva a salir en la misma partida.

3. Las funciones principales del programa

Una función es un conjunto de instrucciones que realiza una tarea determinada. En este juego, cada función se ocupa de una parte del funcionamiento, lo que permite organizar el código y evitar que todas las instrucciones estén mezcladas.

siguiente_pregunta()

Esta función selecciona al azar una pregunta de la lista de preguntas disponibles. Después, elimina su número de la lista, actualiza el texto que aparece en pantalla y guarda en la variable correcta cuál es la respuesta válida para esa pregunta.

iniciar_juego()

Esta función se ejecuta cuando el jugador pulsa el botón "COMENZAR". Oculta la pantalla inicial, muestra las áreas destinadas al cuestionario y llama a siguiente_pregunta() para presentar la primera pregunta.

comprobar(boton)

Esta función se ejecuta cuando el jugador selecciona una respuesta. Recibe el texto del botón pulsado y lo compara con el contenido de la variable correcta.

Si ambos textos coinciden, el programa muestra "CORRECTO" y suma un punto al puntaje. En caso contrario, muestra "INCORRECTO". Luego, actualiza el contador de preguntas y permite continuar según la lógica establecida en el código.

reiniciar_juego()

Esta función se utiliza cuando el jugador pulsa "INTENTAR OTRA VEZ". Restablece el puntaje y el contador de preguntas, vuelve a colocar las diez preguntas en la lista de disponibles, oculta la pantalla de resultados, restablece los botones y prepara una nueva partida.

base.mainloop()

Esta instrucción mantiene abierta la ventana y permite que el programa responda a las acciones del jugador, como pulsar "COMENZAR" o seleccionar una respuesta. Sin este ciclo de funcionamiento, la aplicación no podría seguir esperando las interacciones del usuario.

4. Las variables y los elementos de la pantalla

Además de las funciones, el programa utiliza variables para guardar información y componentes visuales para mostrarla en pantalla.

Variables principales

  • puntaje: guarda la cantidad de respuestas correctas que lleva el jugador.
  • numero_pregunta: lleva la cuenta de las preguntas contestadas y permite determinar cuándo termina la partida.
  • correcta: guarda el texto de la respuesta válida para la pregunta que se está mostrando.
  • preguntas_disponibles: contiene los números de las preguntas que todavía no fueron seleccionadas.

Componentes visuales de Tkinter

  • Frame: permite organizar la ventana en diferentes zonas o secciones.
  • Label: muestra información, como títulos, preguntas, el contador y los resultados.
  • Button: crea los botones que permiten comenzar la partida, seleccionar respuestas o volver a jugar.

Botones, respuestas y lambda

La lista respuestas contiene los textos de las opciones que puede elegir el jugador. El programa recorre esa lista y crea un botón para cada opción, evitando tener que escribir manualmente las instrucciones de cada botón por separado.

La instrucción lambda permite que cada botón envíe su propio texto a la función comprobar(). De esta manera, el programa puede identificar cuál fue la respuesta seleccionada y verificar si es correcta.

5. ¿Cómo funciona una partida paso a paso?

  1. Inicio: se crea la ventana principal y se preparan las pantallas de bienvenida, preguntas y resultados.
  2. Comenzar: el jugador pulsa "COMENZAR" y aparece la primera pregunta, seleccionada al azar.
  3. Responder: el jugador elige una de las opciones disponibles mediante los botones.
  4. Comprobar: el programa compara la opción seleccionada con la respuesta correcta y muestra el resultado.
  5. Actualizar: si la respuesta es correcta, se suma un punto. También se actualiza el contador de preguntas.
  6. Continuar: el juego presenta nuevas preguntas hasta completar las diez, sin repetir las ya seleccionadas durante esa partida.
  7. Resultado final: al terminar, se oculta el cuestionario y aparece la puntuación obtenida.
  8. Volver a jugar: el jugador puede pulsar "INTENTAR OTRA VEZ" para comenzar una nueva partida con el puntaje y el contador en cero.

6. Conclusión

El desarrollo del Cuestionario Lunar permite comprender cómo diferentes herramientas de Python pueden trabajar juntas para crear un juego interactivo. Tkinter se encarga de la interfaz visual, random ayuda a seleccionar las preguntas y las funciones organizan las acciones que realiza el programa.

Aunque cada parte cumple una tarea diferente, todas se complementan para que el jugador pueda responder preguntas, conocer sus resultados y comenzar una nueva partida. De esta manera, el proyecto combina programación y aprendizaje mediante una actividad didáctica sobre la Luna.
