Desarrollo de la aplicación móvil

1. ¿En qué consiste la aplicación?

La aplicación móvil fue desarrollada utilizando MIT App Inventor y forma parte del proyecto educativo "Luna y sus fases". Su objetivo es permitir el control de una maqueta que representa las distintas fases de la Luna mediante un circuito electrónico conectado a Arduino.

La pantalla principal cuenta con una interfaz sencilla, un elemento visual relacionado con la Luna y botones destinados a gestionar la conexión Bluetooth y controlar su representación mediante luces LED.

De esta manera, el usuario puede enviar instrucciones al circuito desde un teléfono móvil, sin necesidad de manipular directamente los componentes físicos. La aplicación funciona como un medio de control entre el usuario y el montaje electrónico.

2. Herramientas utilizadas

Para realizar la aplicación se utilizó MIT App Inventor, una plataforma de desarrollo que permite crear aplicaciones para dispositivos móviles mediante una interfaz visual y bloques de programación.

El entorno de trabajo se divide principalmente en dos partes. El Diseñador permite organizar los elementos visuales de la pantalla, como las imágenes y los botones. Por otro lado, el Editor de bloques permite establecer las acciones que se ejecutan cuando el usuario interactúa con dichos elementos.

Esta forma de programación facilita la comprensión de la lógica de una aplicación, ya que las instrucciones se construyen mediante bloques que representan eventos, acciones y condiciones, en lugar de escribir todo el código manualmente.

3. Componentes principales de la interfaz

La aplicación cuenta con una pantalla principal diseñada para que las funciones sean fáciles de encontrar y utilizar. Sus componentes principales son:

  • Imagen de la Luna: es el elemento visual que relaciona la interfaz con el tema central del proyecto.
  • Botón de Bluetooth: permite gestionar la conexión inalámbrica entre el teléfono móvil y el dispositivo Bluetooth conectado a Arduino.
  • Botón de control de la Luna: está destinado a enviar instrucciones para cambiar la representación visual de las fases lunares mediante las luces LED del circuito.
  • ClienteBluetooth1: es un componente no visible de MIT App Inventor que permite gestionar la comunicación Bluetooth desde los bloques de programación.

La organización de estos elementos busca mantener una interfaz simple y evitar que el usuario tenga que recorrer distintas pantallas para encontrar las funciones principales. La aplicación se concentra exclusivamente en la representación de la Luna de una forma simplificada!

4. Funcionamiento de los bloques

El funcionamiento de la aplicación se establece mediante bloques de programación. Estos indican qué debe suceder cuando se inicia la aplicación, cuando se solicitan permisos o cuando el usuario presiona uno de los botones.

Para utilizar Bluetooth, la aplicación debe solicitar los permisos necesarios y permitir que el usuario seleccione el dispositivo correspondiente, si así lo requiere la configuración utilizada. Una vez seleccionada la conexión, los bloques intentan establecer la comunicación con el dispositivo.

El botón dedicado a la Luna debe ejecutar la acción programada para enviar la instrucción correspondiente a Arduino. La placa recibe esa información y, mediante su propio programa, controla las luces LED para representar el estado seleccionado.

Es importante distinguir entre el diseño visual y la programación: mientras que el Diseñador determina cómo se ve la aplicación, los bloques establecen cómo responde. Ambos trabajan en conjunto para que el control de la maqueta pueda realizarse desde el celular.

5. Conexión Bluetooth y control de las luces

La comunicación entre la aplicación móvil y Arduino se realiza mediante Bluetooth. Esta tecnología permite transmitir información de forma inalámbrica entre dispositivos compatibles, sin necesidad de mantener una conexión física mediante cables entre el celular y la placa durante el control.

El componente ClienteBluetooth1 permite gestionar esta comunicación desde MIT App Inventor. Para que funcione, es necesario que el dispositivo Bluetooth utilizado en el circuito esté conectado correctamente a Arduino y que el celular pueda establecer la conexión con él.

Una vez establecida la comunicación, el botón de control de la Luna puede enviar instrucciones para cambiar el estado de las luces LED. Arduino debe recibir esos datos e interpretarlos mediante el programa cargado en la placa para realizar la acción correspondiente.

Así, la aplicación funciona como una interfaz de control y Arduino se encarga de ejecutar las instrucciones sobre el circuito físico. El funcionamiento correcto depende de que ambos programas utilicen instrucciones compatibles y de que la conexión Bluetooth esté establecida.

6. Pruebas y conclusión

Para comprobar el funcionamiento de la aplicación, es necesario verificar que se puedan conceder los permisos solicitados, que la conexión Bluetooth pueda establecerse y que el botón de control de la Luna envíe las instrucciones correspondientes.

También es importante comprobar que las instrucciones enviadas produzcan la respuesta esperada en las luces LED. Estas pruebas permiten detectar posibles errores tanto en los bloques de MIT App Inventor como en la comunicación con Arduino.

En conclusión, el desarrollo de esta aplicación permitió aplicar conocimientos de programación visual, diseño de interfaces y comunicación inalámbrica. Además, demuestra cómo una aplicación móvil puede utilizarse para controlar un circuito electrónico desde una interfaz sencilla.

¡La aplicación forma parte de una propuesta que integra software, hardware y una representación visual de las fases lunares. De esta manera, el proyecto reúne los conocimientos adquiridos durante el año y los aplica en una experiencia práctica!
